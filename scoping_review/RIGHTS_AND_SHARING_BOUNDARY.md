# Rights and sharing boundary

This package is a **restricted internal validation release** because it contains bulk third-party titles, authors, venues, URLs, and abstracts obtained through scholarly databases. It is suitable for the corresponding author's internal audit, supervisory review, or controlled sharing where database and publisher terms permit.

Do **not** upload the full-text-bearing CSV files or workbook to Zenodo or another public repository without a rights and database-license review. The existing public reproducibility package intentionally releases record identifiers, DOIs where available, decisions, rationales, analytical labels, and fingerprints while omitting bulk title/abstract text.

The original platform-native database export files were not retained. The earliest retained identification object is the normalized 6,512-row `P3-screening.csv` snapshot. This package does not reconstruct or mislabel database-native exports.
